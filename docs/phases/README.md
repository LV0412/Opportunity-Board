# Opportunity Board - Phase Index

Thư mục này tách `docs/PLAN.md` thành các phase nhỏ để build MVP theo từng phần.

## Thứ tự triển khai

| Phase | File | Nội dung |
|---|---|---|
| 01 | `01-project-setup.md` | Khởi tạo frontend, backend, cấu hình local |
| 02 | `02-database-entities.md` | Entity, repository, enum, schema nền tảng |
| 03 | `03-auth-authorization.md` | Auth, JWT, phân quyền role |
| 04 | `04-profiles-storage.md` | Hồ sơ sinh viên, tổ chức, upload CV/logo |
| 05 | `05-opportunity-workflow.md` | Tạo, sửa, duyệt, public opportunity |
| 06 | `06-search-discovery.md` | Search, filter, sort, discovery |
| 07 | `07-bookmarks.md` | Lưu/bỏ lưu cơ hội |
| 08 | `08-applications.md` | Ứng tuyển và application tracker |
| 09 | `09-admin-report-management.md` | Report, quản lý user, taxonomy |
| 10 | `10-notifications-schedulers.md` | Email, reminder, weekly digest |
| 11 | `11-dashboards.md` | Dashboard cho Student, Organization, Admin |
| 12 | `12-ui-validation-docs.md` | UI polish, validation, Swagger/OpenAPI |
| 13 | `13-testing-qa.md` | Unit test, integration test, manual QA |
| 14 | `14-deployment.md` | Chuẩn bị deploy frontend/backend/database |

## Cách dùng

Build lần lượt từ phase 01 đến phase 14. Mỗi phase chỉ nên được xem là xong khi toàn bộ phần **Completion Criteria** trong file phase đó đã đạt.
